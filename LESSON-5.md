## Что сделано

### 1. ClickTimer

- Первый клик только фиксирует startTime, каждый следующий пишет в консоль разницу Date.now() и общее число кликов
- useState не используется, мутация ref не вызывает ререндер

### 2. PreviousInput

- В useState текущее значение а предыдущее в ref, обновляется в useEffect по изменению значения
- Эффект отрабатывает уже после рендера, поэтому в разметке ref ещё держит значение с прошлого рендера

### 3. FocusTracker

- На каждый input свой ref, кнопка дергает firstInputRef.current.focus()
- Счетчик переходов в ref, ререндера нет, число пишется в консоль
- Считаем только переходы между полями: в onFocus сверяем event.relatedTarget с обоими ref, поэтому первый фокус и возврат со стороны кнопки не учитываются

### Дополнительная задача 1. DebouncedLogger

- timeoutId лежит в ref, на каждый onChange старый таймер снимается через clearTimeout, лог уходит только через секунду после последнего ввода
- Стейт не нужен, значение берется из события, поле неуправляемое
- Таймер снимается и в cleanup useEffect, иначе лог прилетит уже после размонтирования

### Дополнительная задача 2. WebSocketLogger

- Соединение создается один раз в useEffect с пустым массивом зависимостей и хранится в ref
- Подписка на message логирует входящие сообщения, в cleanup вызывается socketRef.current?.close()
- Адрес сервера пустой, реального бэкенда для примера нет, важна работа с ref и cleanup

Все компоненты лежат в features/ref-exmaples, страница pages/ref-examples, роут /ref-examples
