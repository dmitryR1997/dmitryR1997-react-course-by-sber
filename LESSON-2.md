## Что сделано

### 1. memo для TaskCard

TaskCard обёрнут в memo. Теперь компонент
перерисовывается только при изменении deps task или onRemove,
Добавлен displayName для читаемости в девтулзах

### 2. useMemo для фильтрации (у меня уже было реализовано в lesson-1)

В хуке useTasks отфильтрованный массив задач
вычисляется через useMemo с deps tasks на filter. При удалении
или изменении статуса меняется ссылка tasks

### 3. useCallback для removeTask (у меня уже было реализовано в lesson-1)

Функция removeTask обёрнута в useCallback с пустым массивом зависимостей.
Используется функциональный апдейт `setTasks((prev) => ...)`, поэтому ссылка
на функцию остаётся стабильной между рендерами. Благодаря этому memo
на TaskCard работает onRemove не создаётся новая ссылка
