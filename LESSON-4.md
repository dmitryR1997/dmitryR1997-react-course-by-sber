## Что сделано

### 1. Форма регистрации на react-hook-form

- Форма лежит в features/register-form, страница — pages/register, роут /register
- Поля подключены через TextField из shared слоя, который подключён к react-hook-form
  (хорошая практика для проекта, чтобы не дублировать везде логику с отображением ошибок и тд)

### 2. Подключение zod

- Схема валидации подключена через zodResolver
- Общие тексты ошибок в shared/config, плюрализация в shared/lib

### 3. Социальные ссылки через useFieldArray

- Массив socialLinks в схеме, каждый элемент — объект с полем url, по умолчанию одно пустое поле
- Кнопки «Добавить ссылку» и «Удалить» дергают append и remove, ключ строки — field.id
- Ссылка валидируется как z.url, ошибка ложится на конкретный индекс (socialLinks.0.url)
- Разрешены только http и https, иначе new URL внутри zod пропускает ftp:/broken и javascript:

### Дополнительная задача: визард на useActionState

- Отдельная фича features/subscribe-wizard, шаг 1 — ввод email, шаг 2 — подтверждение подписки
- Шаг хранится в стейте экшена, форма одна, react-hook-form тут не нужен:
  данные берутся из FormData через action у form
- pending берём третьим значением из useActionState, на время запроса кнопка и поле блокируются
- Ошибка валидации email и финальное сообщение об успехе рендерятся из того же стейта
