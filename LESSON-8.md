## Что сделано

### 1. Tooltip

- Компонент в shared/ui/Tooltip с четырьмя позициями
- Показ по onMouseEnter, скрытие по onMouseLeave, координаты берутся из getBoundingClientRect триггера
- Рендер через createPortal в узел tooltip-root, он добавлен в index.html рядом с root

### 2. События и изоляция

- Тултип не вызывает stopPropagation, поэтому клик по элементу с тултипом свободно всплывает к родителю
- Клик внутри тултипа гасится через stopPropagation: события React всплывают по дереву React, и без этого клик по подсказке ложно срабатывал бы как клик по карточке
- Стили изолированы CSS-модулем, имена классов уникальны и с разметкой приложения не пересекаются
- Наследуемые свойства заданы явно: font, color, letter-spacing, text-align, text-transform, white-space и другие, поэтому типографика страницы на тултип не влияет
- Портал рендерит тултип в tooltip-root вне root, а CSS наследуется по дереву DOM, а не по дереву React, значит стили родителя триггера до тултипа не доходят

### 3. ConfirmDialog

- Компонент в shared/ui/ConfirmDialog, рядом хук useConfirmDialog и модуль стилей
- Диалог рендерится через createPortal в узел dialog-root, он добавлен в index.html
- showConfirmDialog возвращает Promise: resolve хранится в ref и вызывается кнопками, Подтвердить дает true, Отмена и клик по подложке дают false
- Заголовок, описание и подписи кнопок приходят параметрами, у кнопок значения по умолчанию
- Клик по диалогу гасится через stopPropagation, иначе он дошел бы до подложки и закрыл окно

### 4. Страница PortalShowcase

- Страница в pages/portal-showcase, роут /portals
- Первая карточка про события: у нее свои счетчики кликов и наведений, по ним видно, что тултип не мешает родительским обработчикам
- Карточке специально заданы некоторые стили, тултип их не наследует
- Вторая карточка про диалог кнопка Удалить ждет showConfirmDialog, по подтверждению элемент удаляется

### Дополнительная задача. Тема через контекст

- ThemeContext, ThemeProvider и useTheme лежат в shared/lib/theme, провайдер подключен в App
- Tooltip и ConfirmDialog берут тему хуком useTheme и вешают на себя класс light или dark
- Переключатель темы стоит на странице PortalShowcase
